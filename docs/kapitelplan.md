# Kapitelplan

## Översikt

## Inledning

- Syfte: Vad som gör en soppa god, hur boken är upplagd och hur läsaren utvecklas från nybörjare till trygg soppkock.
- Format: receptdrivet lärande med tillagningstid, svårighetsgrad, teknikfokus, smakprofil och vanliga misstag.
- Progression: bygger vidare på tidigare tekniker och smakbegrepp.
