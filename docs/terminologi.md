# Terminologi

## Smakbas
Den första smakgrunden i en soppa, ofta lök eller annan aromatisk råvara som tillagas i fett.

## Buljong
Smaksatt vätska som ger soppan kropp och djup.

## Umami
Fyllig, rund smak som ofta kommer från svamp, tomat, lagrad ost, miso, soja eller rostade råvaror.

## Smakbalans
Hur sälta, syra, sötma, beska, hetta, fett och umami samspelar.

## Topping
Något som läggs ovanpå soppan vid servering för smak, textur eller kontrast.

| Begrepp | Definition | Användning |

| Svetta | Att tillaga råvaror lugnt i fett så att de mjuknar utan att få färg. | Används för milda, runda soppor. |

| Bryna | Att låta råvaror få färg för att skapa djupare smak. | Särskilt viktigt senare för svamp, lök och rotfrukter. |

## Kapitel 13: Räddning och felsökning

- **Felsökning:** Att smaka systematiskt och identifiera ett problem i taget.
- **Slutjustering:** Små ändringar före servering, oftast salt, syra, fett, umami eller arom.
- **Osaltad volym:** Osaltad vätska eller råvara som minskar upplevd sälta.
- **Räddningstopping:** Topping som används för att balansera smak eller textur, inte bara dekorera.
